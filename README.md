\## 📋 Installation



```bash

git clone https://github.com/USERNAME/odoo-18.git

```



Copy the desired module into your custom addons directory:



```bash

cp -r module\_name /odoo/custom/addons/

```



Update Apps List and install the module from Odoo Apps.
